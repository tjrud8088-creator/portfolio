포트폴리오 사이트 파일 모음 (Deft 케이스 스터디 반영본)

이 폴더 안의 "모든 파일과 폴더"가 사이트 전체입니다.
(about.html, case-study.html, index.html, work.html 등 + css 폴더 + js 폴더 + img 폴더)

올리는 방법
1. GitHub에서 포트폴리오 저장소를 엽니다.
2. Add file > Upload files 를 누릅니다.
3. 이 폴더를 열어 안에 있는 모든 것을 선택(Ctrl+A)해서 업로드 창에 끌어다 놓습니다.
   (이 안내 파일 "읽어주세요.txt"는 빼도 됩니다.)
4. 같은 이름의 파일은 덮어쓰이고, 새 파일은 추가됩니다.
5. 맨 아래 Commit changes 를 누릅니다.
6. 몇 분 뒤 아래 주소를 Ctrl+F5로 새로고침해서 확인합니다.
   https://tjrud8088-creator.github.io/portfolio/case-study.html
